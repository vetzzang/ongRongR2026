# 옹알옹알

어학 쉐도잉 웹앱(PWA). 음성 파일을 문장 단위로 끊어 반복 청취하고,
파형·성조 곡선·5줄 대본(성조/병음/한자/독음/뜻)·srt 자막을 함께 보여줍니다.

## 깃허브 페이지스로 배포

1. 이 폴더의 내용을 저장소 **루트**에 올립니다 (index.html 이 루트에 있어야 합니다)
2. 저장소 → Settings → Pages → Branch 를 `main`(루트)으로 지정
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 접속

모든 경로가 상대 경로라 하위 주소에서도 그대로 동작합니다.
휴대폰·태블릿에서 열고 "홈 화면에 추가"를 누르면 앱처럼 설치되고 오프라인에서도 열립니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 앱 전체 (단일 파일) |
| sw.js | 오프라인 캐시 (서비스워커) |
| manifest.webmanifest | 설치용 메타데이터 |
| pack.json + audio/ | 기본 예문 팩 (중국어 3문장) |
| icon-*.png 등 | 앱 아이콘 |

## 쓰는 법

- 폴더 버튼: mp3 와 같은 이름의 .srt 를 이름으로 짝지어 한 번에 불러옵니다
- srt 가 있으면 자막 시각이 문장 경계가 되고, 3단 파형 밑 띠에 실시간 표시됩니다
- 설정 → 대본 5줄: 카드 길게 눌러 줄 순서 변경, 줄별 크기 조절

## 새 버전을 올릴 때

index.html 의 `APP_VERSION` 과 sw.js 의 `CACHE_NAME` 을 같은 값으로 올려야
설치된 기기들이 새 버전을 받습니다.
